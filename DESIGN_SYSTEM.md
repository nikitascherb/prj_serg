# ЩЕРБИНИНЫ / DESIGN SYSTEM V2

## Принцип
Тихая уверенность, ясная структура, никаких агрессивных маркетинговых обещаний. Сайт движется от executive summary к компетенциям, методу, самостоятельной диагностике и обращению.

## Цвет
- Canvas `#0c0b0a`
- Surface `#151310`
- Gold `#c9a46b` — акцент, не фон для длинных текстов
- Ivory `#f1e9dc`
- Light section `#eae3d8`
- Focus `#f0c98d`

## Геометрия
- XS 8px — мелкие элементы
- SM 12px — поля
- MD 18px — карточки, панели, кнопки
- LG 24px — модальные окна
- XL 32px — крупные контейнеры

## Типографика
- Prata: редакционные заголовки
- Manrope: UI, текст, подписи
- Не использовать разреженные буквы для абзацев
- Контраст и доступность важнее декоративности

## Изображения
- Никаких градиентов/масок поверх букв и логотипов
- Герб показывать целиком, `object-fit: contain`
- Фотографии — без сильного затемнения, не использовать макеты интерфейса как картинки интерфейса
- Использовать исходные брендовые изображения только в отдельных медиа-контейнерах

## Интеракции
- Hover: не более 1–2px
- Press: `translateY(2px) scale(.985)` и возврат
- Reveal: лёгкое смещение 18px, 750ms
- `prefers-reduced-motion` обязателен
- Системный focus-visible вместо синего браузерного контура

## Контент
- Проблема → экспертиза → подход → результат → обращение
- Не обещать рост выручки или гарантированный результат
- Психотерапевтические услуги отделять от корпоративного консалтинга
- Не собирать терапевтические или медицинские подробности в публичной форме

## Технические границы
- GitHub Pages поддерживает статический фронтенд
- Отправка формы включается только после настройки `config.js` и утверждения политики
- Серверная обработка обращений — Formspree или собственный backend

## V3 / Навигационная архитектура
- Главная: Executive Summary → области экспертизы → навигатор → обращение
- Экспертиза: контекст запроса → что анализируем → возможный артефакт
- Подход: этапы → критерии → границы ответственности
- Сценарии: шесть типовых ситуаций без вымышленных клиентских результатов
- Материалы: инструменты и вопросы для самостоятельной подготовки
- Обращение: валидируемая форма, явное согласие, состояние загрузки, результат сохранения

## Мобильная версия
- Breakpoint меню 1100px; мобильная панель навигации без переполнения
- Колонки переходят в 2 и 1; поля формы — в одну колонку
- Герб сохраняет исходные пропорции 1280:975, не обрезается, без mask/clip/gradient поверх
- iOS/Android: viewport-fit, системный focus-visible, responsive widths, reduced motion
