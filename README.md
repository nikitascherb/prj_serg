# ЩЕРБИНИНЫ — UI MVP

Полноценный адаптивный статический сайт, а не PNG-макет. Использует подготовленные бренд-ассеты в `/assets`.

## Возможности
- Адаптивный интерфейс и мобильное меню
- Пять направлений консалтинга с интерактивными модальными окнами
- Навигатор бизнес-задач с рекомендацией по направлению
- Локальное формирование и скачивание текстового брифа (без отправки данных)
- Семантическая HTML-разметка, базовая доступность, SEO-метаданные

## Запуск
Откройте `index.html` в браузере или запустите `python -m http.server 8000` из этой папки.

## GitHub Pages
Скопируйте `index.html`, `styles.css`, `app.js` и каталог `assets/` в корень ветки `main` репозитория. В GitHub откройте Settings → Pages → Deploy from a branch → main / (root) → Save.

## Ограничения
Это работающий **frontend MVP**: нет приёма заявок, CRM, авторизации и базы данных. Кнопка скачивания формирует файл локально. Контактные данные, цены, кейсы и юридические реквизиты не выдуманы. Перед публичным запуском нужно согласовать сведения об исполнителе, политику персональных данных при подключении форм и формулировки регулируемых услуг.
