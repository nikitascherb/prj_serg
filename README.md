# Щербинины — UX/UI v2

Статический сайт для GitHub Pages. Включает полноценную адаптивную верстку, каталог услуг, навигатор задач, модальные окна и форму обращения с клиентской валидацией.

## Развертывание
1. Загрузите содержимое этой папки в ветку `new-one`.
2. GitHub → Settings → Pages → Deploy from a branch → `new-one` / `(root)`.
3. Проверьте `https://nikitascherb.github.io/prj_serg/`.

## Как включить приём заявок
1. Создайте форму в Formspree, подтвердите email владельца и получите endpoint `https://formspree.io/f/XXXXXXXX`.
2. Подготовьте и опубликуйте настоящую политику обработки данных с реквизитами оператора; шаблон `privacy.html` сейчас НЕ является завершённым юридическим документом.
3. В `config.js` укажите `formEndpoint: 'https://formspree.io/f/XXXXXXXX'`.
4. Протестируйте отправку с опубликованного сайта, уведомление на почту и обработку ошибки.
5. Настройте защиту от спама и сроки хранения данных в Formspree.

До выполнения этих шагов форма **не отправляет данные**, не показывает ложного подтверждения и сообщает, что канал не подключён.
