# Щербинины — рабочее MVP

Функции: адаптивный сайт, каталог услуг, форма обращения с серверной валидацией, сохранение заявок в SQLite, парольный кабинет команды, статусы заявок, заметки, экспорт CSV.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
export SECRET_KEY='replace-with-long-random-value'
export ADMIN_PASSWORD='replace-with-strong-password'
python app.py
```

Откройте http://127.0.0.1:5000 . Админка: http://127.0.0.1:5000/admin . Для сервера используйте `gunicorn app:app` с HTTPS и постоянным диском для SQLite либо замените БД на управляемую PostgreSQL.

## Важно перед публичным запуском

1. Настройте постоянную БД, резервное копирование, HTTPS и секреты окружения. SQLite на эфемерном хостинге теряет данные при пересоздании инстанса.
2. Добавьте юридические документы: политику персональных данных, реквизиты оператора и механизм удаления заявок. Настройте сроки хранения и доступ сотрудников.
3. Добавьте защиту от спама / rate limiting, CSRF-защиту для админских POST-запросов, 2FA и журнал действий до масштабирования.
4. Подключите почтовые уведомления через транзакционный email-сервис (сейчас обращения сохраняются в кабинете, но email не отправляется).
5. Согласуйте реальные условия оказания юридических и психоаналитических/терапевтических услуг и квалификационные ограничения.

Изображения основаны на предоставленных пользователем фирменных визуалах. Сайт не содержит вымышленных кейсов, отзывов или обещаний результата.
